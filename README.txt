Moisture Prediction Project - Configured Runtime Package

1. Project Task
This package is configured for the paper/course experiment:
use loose-conditioning process parameters and historical HT inlet moisture
to predict the next 4 time steps of HT inlet cut-tobacco moisture.

2. Key Experiment Settings
- Source data required by code: data/combined_result2.0.xlsx
- Dataset status in this repository: the Excel data file is not included.
  See input_data/README.md for the data description and external data note.
- Historical window: 16
- Prediction horizon: 4
- Split: chronological 70% train, 15% validation, 15% test
- Models: MLP, CNN, LSTM, GRU, BiLSTM, CNN-LSTM, Proposed
- Ablations: Full Model, w/o Multi-scale CNN, w/o Attention, w/o Residual, w/o Auxiliary Loss

3. Folder Layout
- src/models.py: model definitions
- src/run_experiments.py: training, evaluation, metrics, and figures
- requirements.txt: Python dependency list
- project_requirements.json: structured experiment requirements and package status
- input_data/README.md: data description and data access note
- output/results/: existing packaged result tables
- output/figures/: existing packaged figures
- docs/实验说明与论文使用指南.docx: experiment and paper usage guide
- data/: optional local data folder, not included in the current repository
- results/: generated by a new run of src/run_experiments.py
- figures/: generated by a new run of src/run_experiments.py
- checkpoints/: optional model checkpoints, created on demand when --save-checkpoints is used

4. Create Virtual Environment
Open PowerShell or cmd in this folder, then run:

python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt

No one-click setup/startup script is included. Create the environment manually
with the commands above.

5. Prepare Data
The current repository does not contain the Excel data file. Before running the
default command, place the dataset at:

data/combined_result2.0.xlsx

Alternatively, pass a custom Excel path with --data:

.venv\Scripts\python.exe src\run_experiments.py --data path\to\your\data.xlsx

The target column name must remain:

叶丝膨胀干燥_HT入口叶丝含水率

6. Run Experiments
After installing dependencies and preparing the data:

.venv\Scripts\python.exe src\run_experiments.py

Optional quick comparison-only run:

.venv\Scripts\python.exe src\run_experiments.py --skip-ablation

Optional CPU run:

.venv\Scripts\python.exe src\run_experiments.py --device cpu

Optional checkpoint saving:

.venv\Scripts\python.exe src\run_experiments.py --save-checkpoints

7. Output Locations
Existing packaged outputs are stored in:

output/results/
output/figures/

A new run of src/run_experiments.py writes tables to results/ and figures to
figures/ at the repository root.

8. Notes
The original data are collected by time step in row order. This package therefore
uses row order as the implicit chronological index, consistent with the project note.

The Python files src/models.py and src/run_experiments.py compile successfully
in the local Anaconda environment used for this package check.
